# 轻燃

记录每次运动，看见每一点改变。

基于 [openGym](https://github.com/DuarteSantos8/openGym) 的个人中文健身应用。
第一阶段保留上游训练记录、统计、PWA 和 AI 教练能力，增加中文默认配置、轻燃品牌和本地启动入口。

## 本地运行

需要 Node.js 24 和 npm。在仓库根目录执行：

```sh
npm run setup
npm run dev
```

打开 http://localhost:5173 。首次可使用访客模式体验；需要同步和 AI 时创建个人账户。
本地账号与训练数据保存在 `data/`（已排除 Git）。首个注册用户的管理员权限规则沿用上游。
`npm run build` 生成 `frontend/dist/`；生产部署必须配套 API，不能仅上传静态文件期待账号和 AI 工作。

## 第一阶段能力

- 简体中文默认界面；手动选择的其他语言仍被保留。
- 训练计划、组数/重量/次数记录、历史、体重和训练统计：继承上游实现。
- iPhone PWA 清单、主屏幕名称和离线基础：继承上游并设置 轻燃名称。需部署 HTTPS 后，在 Safari 分享菜单选择“添加到主屏幕”；本机 localhost 地址不能直接在 iPhone 使用。尚未进行真机安装验收。
- AI 私人教练：继承上游计划生成、训练历史分析、训练复盘、调整提案、确认后应用及撤销机制。未连接模型时不伪造 AI 结果。

## 饮食记录（新增）

首页进入“饮食记录与统计”：按日期新增、编辑、删除三餐和加餐；手动填写实际份量的热量及可选蛋白质、碳水、脂肪，标注是否估算。展示当天合计和近 7 天摄入。空白营养素不计入汇总，无记录日显示“未记录”。数据使用现有档案持久化与同步机制。新增本地食物搜索：USDA SR Legacy 7,793 条完整热量和三大营养素数据，其中 29 条常见食物有中文名称，其他可用英文搜索。选择食物并填写可食部分克数，自动换算并保存来源快照；仍支持手动填写。当前不包含拍照识别或 AI 饮食分析。来源与更新方式见 [食物数据说明](docs/FOOD_DATA.md)。

## 配置真实 AI

创建账户后进入“设置 → 账户 → 管理后台 → AI 教练”，启用服务，选择模型提供方，在应用中填写自己的 API key 或兼容端点，列出模型并测试连接。随后从“计划”菜单进入教练，阅读数据发送说明并填写目标、经验、器械与训练频率。模型给出的改动需要确认才会应用。
不要把密钥写入代码或提交 Git。当前没有配置真实凭据，因此尚未完成真实模型联调。详细能力和数据边界见 [上游 AI 文档](docs/AI_COACH.md)。
